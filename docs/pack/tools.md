# The vessel

**prim-viewer** is how a person looks at a Prim. It is a Prim Tool: surface, talk, cites `*`. It is not a Prim.

```html
<script type="module" src="showprim.js"></script>
<show-prim src="/docs/pack/"></show-prim>
```

The tag is the pairing. This page is `/docs`. The pack is `docs/pack/`. Hosting the tag does not make the host a Prim.

A view can be customized apart from the data. A pack may compose a view in with the data when you want to ship both. Pull the view out and the data still stands.

WebMCP lives on the same tag. A model talks to the open prim. It does not scrape the page.
